# What Is Mobile Gaming?

Mobile gaming is playing video games on mobile devices such as smartphones and tablets. Mobile games can be downloaded from app stores and can include many different types of games. Some mobile games are free to play, while others cost money or offer optional purchases.

### Common Types of Mobile Games

Some common types of mobile games include:

- Puzzle games
- Strategy games
- Role playing games
- Action games
- Simulation games
- Multiplayer games
- Sports games
- Casual games

Puzzle games are popular on mobile devices because they are usually easy to pick up and play. Players can complete short challenges while waiting or taking a break.

Strategy and simulation games can give players longer experiences. These games can involve building cities, managing resources, or planning how to complete different goals.

Role playing and action games can also be found on mobile devices. Some mobile games have larger worlds, stories, and online features similar to games on consoles and PCs.

## Modern Examples

Some popular mobile games include:

- **Genshin Impact**: An action role playing game with an open world, exploration, combat, and a large story.
- **PUBG Mobile**: A multiplayer battle royale game where players compete to be the last player or team standing.
- **Pokémon GO**: A mobile game that uses location and augmented reality features to let players find and catch Pokémon.
- **The Sims FreePlay**: A simulation game where players can create Sims, build homes, and manage their daily lives.
- **Candy Crush Saga**: A puzzle game where players match different pieces to complete levels.
- **Call of Duty: Mobile**: A multiplayer action game that includes different game modes and online competition.

### What Makes Mobile Gaming Different?

Mobile gaming is different because it allows people to play games almost anywhere using a device they may already own. Many mobile games are also designed around shorter play sessions, making them easy to play for a few minutes at a time.

Mobile games can use touchscreen controls, motion controls, location features, and other features that are available on smartphones and tablets.

### What I Would Play

I would probably play mobile games when I want something quick and easy to play without sitting at my computer or console. I like having the option to play a game wherever I am.
