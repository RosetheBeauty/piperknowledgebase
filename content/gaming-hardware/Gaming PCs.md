## What Is a Gaming PC?

A gaming PC is a computer that is used to play video games. Gaming PCs can be built in many different ways, which is one of the things that makes them interesting. Some people buy a computer that is already built, while other people build their own computer using different parts.

### Important PC Parts

There are a few important parts that help a gaming PC work.

- CPU
- GPU
- RAM
- Storage

The CPU helps the computer process information. The GPU is important because it handles the graphics in games. RAM helps the computer run programs and games, while storage is where games and other files are saved.

## Upgrading a PC

One thing I like about gaming PCs is that you can upgrade different parts. Someone could replace their graphics card, add more RAM, or get more storage instead of buying a whole new computer. This can help a PC last longer.

A gaming PC also works with [[Gaming Monitors]] because the computer's hardware can affect the resolution and refresh rate that the monitor can use.

### Hardware and Software

Gaming PCs also need [[Gaming Software]] to run games and other programs. The hardware and software work together to make everything run correctly.
