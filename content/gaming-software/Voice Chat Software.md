# What Is Voice Chat Software?

Voice chat software allows people to communicate with each other using their voices over the internet. Gamers often use voice chat while playing multiplayer games so they can talk to friends, teammates, and other players.

Voice chat can be built into a game or provided through a separate app. Some programs also include features such as text chat, video calls, screen sharing, and private group channels.

### Common Types of Voice Chat Software

Some common voice chat software includes:

- Discord
- Xbox Party Chat
- PlayStation Party Chat
- Steam Voice Chat
- TeamSpeak
- In game voice chat

Discord is commonly used by gaming communities because it allows people to create servers, voice channels, and text channels.

Xbox Party Chat and PlayStation Party Chat allow players to talk with friends while using their gaming consoles.

Steam also provides voice communication features that allow players to talk with friends while using the platform.

TeamSpeak is another voice communication program that has been used by gaming communities for many years.

## Modern Examples

Some popular voice chat options include:

- **Discord**: A communication platform with voice channels, text chat, video calls, and screen sharing.
- **Xbox Party Chat**: A voice chat feature that allows Xbox players to communicate with friends.
- **PlayStation Party Chat**: A feature that allows PlayStation players to talk with friends through voice chat.
- **Steam Voice Chat**: A voice communication feature available through Steam.
- **TeamSpeak**: Voice communication software that allows users to communicate through dedicated servers.
- **In Game Voice Chat**: Voice chat built directly into multiplayer games so players can communicate while playing.

### What Makes Voice Chat Software Different?

Voice chat software is different because it allows players to communicate without having to type messages while playing. This can be especially useful in multiplayer games where players need to communicate quickly.

Different programs also offer different features. Some focus mainly on voice communication, while others include text chat, video, screen sharing, communities, and other tools.
