# What Are Game Engines?

Game engines are software programs used to create and develop video games. They give developers tools for creating things such as graphics, sounds, characters, environments, physics, and gameplay. Using a game engine can make the game development process easier because developers do not have to create every part of a game from the beginning.

### Common Types of Game Engines

Some common game engines include:

- Unreal Engine
- Unity
- Godot
- GameMaker
- CryEngine
- RPG Maker

Unreal Engine is used to create games with detailed graphics and large environments. It is commonly used for both video games and other types of 3D experiences.

Unity is a popular game engine that can be used to create 2D and 3D games. It is also used to make games for different platforms, including computers, consoles, and mobile devices.

Godot is an open source game engine that can be used to create both 2D and 3D games. It is popular with independent developers because it provides many development tools without requiring a large development team.

GameMaker focuses on making 2D games and is often used by smaller developers and people who are learning how to make games.

## Modern Examples

Some popular games made with different game engines include:

- **Fortnite**: Developed using Unreal Engine and known for its large online multiplayer world.
- **Hollow Knight**: A 2D action adventure game developed using Unity.
- **Cuphead**: A 2D action game known for its hand drawn animation style and challenging gameplay.
- **Stardew Valley**: A farming and life simulation game that was developed by an independent developer.
- **Godot projects**: Many independent developers use Godot to create smaller games and experimental projects.

### What Makes Game Engines Different?

Game engines are different because they provide different tools and features for developers. Some engines focus more on 2D games, while others are designed for detailed 3D games.

The engine a developer chooses can depend on the type of game they want to create, the platforms they want to support, and how much experience they have with game development.

Game engines can also include tools for creating graphics, physics, animations, sounds, levels, and other parts of a game.

### What I Would Use

If I was making a game, I would probably want to use an engine that is easy to learn and has plenty of tools available. I would also want an engine that could support the type of game I wanted to create.

> I think game engines are interesting because they give developers the tools they need to turn an idea into an actual game.
